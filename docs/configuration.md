# Configuration reference

The YAML file makes reconciliation and quality decisions reviewable. Column
names always refer to the original CSV headings.

## Parent submission

- `id_column`: immutable submission identifier generated by the collection platform.
- `entity_key`: business identifier used to group possible corrections.
- `status_column`: review state used in ranking.
- `timestamp_column`: ISO 8601 submission time used after status priority.

## Status priority

`status_priority` maps each accepted status to an integer. A larger number has
greater authority. This means an older approved submission can outrank a newer
rejected correction.

## Repeat groups

Each named group defines its own parent-link column and record identifier. A
repeat row linked to a known but non-authoritative submission is excluded even
when `keep_orphan_repeats` is true. That setting applies only when the parent
identifier is completely absent from the parent input.

## Quality checks

The optional `quality` section configures the reported household-size column,
member-age column, valid age range, and severity of each rule. Quality checks
are non-destructive: an issue is reported in `quality_issues.csv`, but the
source value is not silently repaired or removed.
